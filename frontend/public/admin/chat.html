검색 모드

  • Dense — 기존 의미 검색(코사인 거리 1024d). 분위기·맥락에 강함.
  • Hybrid (D+S) — dense + sparse(BGE 어휘 가중치). 영문·숫자·품번 매칭에 강함.
  • 형태소 체크 — 추가로 Kiwi 한국어 형태소 매칭(TF-IDF)을 켬. "여름·가방·목걸이" 같은 한국어 단어 단위 매칭. BGE sparse 가 음절로 쪼개 놓치는 부분을 보완.
  • ColBERT 체크 — 1차 결과(dense 또는 hybrid)를 ColBERT MaxSim 으로 재정렬(rerank). 토큰별 정밀 매칭으로 상위 후보 순서를 다듬음. dense·hybrid 어느 모드와도 조합 가능 (dense+ColBERT, hybrid+ColBERT, hybrid+형태소+ColBERT 등).

융합(fusion) — 두 점수를 합치는 방식

RRF (Reciprocal Rank Fusion) 기본 추천
점수 값 대신 순위로 합산: α/(60+dense순위) + (1-α)/(60+sparse순위). 스케일 정규화 불필요해서 안정적이고 튜닝 부담이 적음. 모르면 이걸 두세요.
α-가중합 (Weighted Sum)
후보 점수를 0~1로 정규화한 뒤 평균: α·dense + (1-α)·sparse. 점수 차이까지 반영되지만 쿼리마다 결과가 살짝 흔들릴 수 있음.

α 슬라이더 — dense 가중치

슬라이더 값 = α = dense 에 주는 가중치. sparse 가중치는 (1−α).

슬라이더 위치 α 의미
맨 왼쪽 (sparse 쪽)0.0단어 정확 매칭만
0.30.3sparse 70% + dense 30%
가운데 (기본)0.5균등 50:50
0.70.7dense 70% + sparse 30%
맨 오른쪽 (dense 쪽)1.0의미 매칭만

언제 어떻게 쓰면 좋나

  • 품번·브랜드명·"14K" 같이 정확 단어가 중요 → α 낮춰 sparse 비중↑ (예: 0.3)
  • "봄에 데이트하기 좋은" 같은 분위기·맥락 → α 높여 dense 비중↑ (예: 0.7)
  • 잘 모르겠으면 → RRF + α=0.5 (기본값)
