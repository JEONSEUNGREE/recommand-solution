RRF score 관점 단위 융합 신호별 채택 관점 저장

RRF 공식
score(행) =   w_dense / (60 + rank_dense)  + w_sparse / (60 + rank_sparse)  + w_morph / (60 + rank_morph)
가중치 (α=0.5, 형태소 1/3): w_dense≈0.333, w_sparse≈0.333, w_morph≈0.333
처리 과정
# ① 모든 행에 dense/sparse/morph 랭킹 부여 # dense_dist 오름차순 → rank_dense = 1,2,3,... # sparse_ip 오름차순 → rank_sparse = 1,2,3,... # morph_ip 오름차순 → rank_morph = 1,2,3,... # ② 각 행 RRF score 계산 (K=60) row[1234,situation]: 0.333/(60+3) + 0.333/(60+8) + 0.333/(60+4) = 0.01620 row[1234,material]: 0.333/(60+7) + 0.333/(60+2) + 0.333/(60+11)= 0.01541 row[2087,material]: 0.333/(60+4) + 0.333/(60+1) + 0.333/(60+2) = 0.01598 ... # ③ 상품별 그룹핑 → 최고 score 행 = 대표 관점 상품 1234 → 대표: situation (score 0.01620) → dense_best: material (dense_dist 최소) → sparse_best: material (sparse_ip 최소) → morph_best: situation (morph_ip 최소) # ④ top-50 반환 (ColBERT 후보용)

MaxSim 공식
score(q, d) =  Σᵢ max_j ( q_i · d_j )
각 쿼리 토큰 q_i에 대해 → 상품 토큰 d_j 중 내적이 가장 큰 값 → 합산
NumPy: sims = q_mat @ d_mat.T → sims.max(axis=1).sum()
처리 과정 — "봄 데이트 14k 귀걸이" 예시
DB에서 50개 상품 colbert_vecs 조회 → 쿼리 토큰별 최대 내적 찾기
봄 → 상품 최근접 토큰: 봄, 봄날, 스프링 → max = 0.892
데이트 → 상품 최근접 토큰: 데이트, 로맨틱 → max = 0.871
14 → 상품 최근접 토큰: 14, 14k → max = 0.934
k → 상품 최근접 토큰: k, 골드, 금 → max = 0.811
귀걸이 → 상품 최근접 토큰: 귀걸이, 이어링 → max = 0.956
colbert_score = 0.892 + 0.871 + 0.934 + 0.811 + 0.956 + ... = 12.43
