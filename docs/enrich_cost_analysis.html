Q&A

Q1. input_tokens이 281인데 시스템 프롬프트 800tok + 스키마 900tok은 어디 있나요?
Claude는 토큰을 4개 버킷으로 분리 청구합니다.
input_tokens 281 = 상품별 텍스트만 / cache_creation 76,301 = 시스템프롬프트(800) + 스키마(900) + 이미지(~74,600)
800+900 토큰은 cache_creation 안에 포함되어 있습니다. 처음 쓸 때 cache_creation($1.00/MTok)으로 기록되고, 5분 내 재호출 시 cache_read($0.08/MTok)로 92% 절약됩니다.
Q2. Claude API 직접 호출도 캐시가 동일하게 적용되나요?
네. 프롬프트 캐싱은 Anthropic API 자체 기능으로 CLI와 동일합니다. API 호출 시 "cache_control": {"type": "ephemeral"}을 캐시할 블록에 명시해야 하며, 현재 코드에 이미 적용되어 있습니다 (DB의 cache_creation/cache_read 값으로 확인됨).
Q3. 검색 시 GPT-4o-mini는 어떤 역할을 하나요?
사용자의 자연어 검색어를 구조화된 JSON으로 변환합니다.
예) "30대 직장 여성 귀걸이" → target_gender: 여성, target_age_min: 30, category_contains: 귀걸이, semantic_query: "직장 여성 데일리 귀걸이"
이 결과로 벡터 검색(임베딩 유사도)과 정형 필터(성별/연령/카테고리)를 동시에 적용합니다. 실측 기준 검색 1건당 평균 $0.000229 (약 0.33원)입니다.
Q4. GPT-4o-mini로 Enrich 바꾸면 얼마나 싸지나요?
Output 요금 차이가 주 원인: Claude 3.5 Haiku $4.00/MTok vs GPT-4o-mini $0.60/MTok (6.7배 차이).
단순 토큰 수 대입 추정 시 상품 1개 ~$0.010으로 현재 대비 약 15배 절감 예상.
단, 이미지 토큰 계산 방식이 달라 실제 차이는 다를 수 있으며, 한국어 인포그래픽 OCR 품질 검증이 필요합니다.
